🚀 V2Ray کانفیگ مدیر

ساخت و مدیریت کانفیگ‌های V2Ray

💡 برای استفاده از این کانفیگ‌ها، نیاز به نرم‌افزار V2Ray دارید. لطفاً از منابع معتبر دانلود کنید.
📋 VLESS (Recommended)
vless://[UUID]@[SERVER]:443?encryption=none&security=tls&sni=[DOMAIN]&type=ws&host=[DOMAIN]&path=/v2ray#V2Ray-VLESS
📋 VMess
vmess://[BASE64_ENCODED_CONFIG]
📋 Trojan
trojan://[PASSWORD]@[SERVER]:443?security=tls&sni=[DOMAIN]&type=ws&host=[DOMAIN]&path=/trojan#Trojan-Config
📋 JSON Config
{
  "inbounds": [
    {
      "port": 10808,
      "protocol": "socks",
      "settings": {
        "auth": "noauth"
      }
    }
  ],
  "outbounds": [
    {
      "protocol": "vless",
      "settings": {
        "vnext": [
          {
            "address": "[SERVER]",
            "port": 443,
            "users": [
              {
                "id": "[UUID]",
                "encryption": "none"
              }
            ]
          }
        ]
      },
      "streamSettings": {
        "network": "ws",
        "wsSettings": {
          "path": "/v2ray",
          "headers": {
            "Host": "[DOMAIN]"
          }
        },
        "security": "tls",
        "tlsSettings": {
          "serverName": "[DOMAIN]"
        }
      }
    }
  ]
}
⚙️ نکات مهم:
- جای‌نشان‌گرهای [UUID], [SERVER], [DOMAIN] را با مقادیر واقعی جایگزین کنید
- برای امنیت بیشتر، از TLS استفاده کنید
- این کانفیگ‌ها برای استفاده تست است
